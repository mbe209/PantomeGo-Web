# PantoMeGo Web

Offizielle Web-Präsenz und Landing Page für **PantoMeGo** – Das kinderfreundliche Pantomime- und Scharadespiel für die ganze Familie.

🌐 **Website:** [https://www.pantomego.app](https://www.pantomego.app)  
✉️ **Kontakt:** hello@pantomego.app  
🍎 **App Store:** [PantoMeGo im App Store](https://apps.apple.com/app/pantomego/id6743128905)

## Struktur
- `index.html`: Responsive Landing Page (4 Sprachen: DE, EN, ES, FR)
- `support/`: Support Center & Eltern-FAQ
- `privacy/`: DSGVO- und Apple Kids Category-konforme Datenschutzerklärung
- `assets/`: Icons, Badges und Mockups
- `CNAME`: Domain-Routing für GitHub Pages (`www.pantomego.app`)
